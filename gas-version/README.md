## セットアップ手順(15分・全部ブラウザだけでできます)

### 1. スプレッドシートを作る

1. https://sheets.new を開く(新しいスプレッドシートが作られます)
2. 左上の「無題のスプレッドシート」をクリックして、名前を付ける(例:「ラジオ体操スタンプラリー」)

### 2. プログラムを貼り付ける

1. メニューの「**拡張機能**」→「**Apps Script**」をクリック(新しいタブが開きます)
2. 左側の「コード.gs」を開き、中身を全部消して、**`Code.gs` の内容を丸ごと貼り付け**る
3. 左側の「ファイル」の横の「+」→「**HTML**」をクリックし、ファイル名を **index** にする
4. できた index.html の中身を全部消して、**`index.html` の内容を丸ごと貼り付け**る
5. 上の💾(保存)を押す

### 3. 初期設定を実行する

1. 上のツールバーの関数を選ぶところ(「doGet」などと出ている場所)で「**setup**」を選ぶ
2. 「**実行**」を押す
3. 初回は「承認が必要です」と出るので:「権限を確認」→ 自分のアカウントを選択 →
   「詳細」→「(プロジェクト名)に移動」→「許可」
   (自分で作ったプログラムに自分のシートの読み書きを許可する、という意味です)
4. スプレッドシートのタブに戻ると「**設定**」「**ごほうび**」「**出席**」の3枚のシートができています

### 4. 公開してURLをもらう

1. Apps Scriptの画面右上の「**デプロイ**」→「**新しいデプロイ**」
2. 左の⚙(歯車)→ 種類で「**ウェブアプリ**」を選ぶ
3. 設定はこの2つだけ確認:
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」を押すと `https://script.google.com/macros/s/…/exec` というURLが発行されます
5. **このURLをコピーして、オフィス(oVice等)やZoomチャットに貼れば完成!**

### 5. 動作確認のコツ

「設定」シートの「テストモード」を `TRUE` にすると、受付時間外でもスタンプが押せます。
自分で試して動きを確認したら、`FALSE` に戻してください(シートを書き換えるだけで即反映されます)。

## ふだんの運用

- **タイトル・期間・受付時間を変えたい** → 「設定」シートの値を書き換えるだけ(再デプロイ不要)
- **賞を変えたい** → 「ごほうび」シートを書き換えるだけ
- **誰がどれだけ参加したか見たい** → 「出席」シートを開くだけ(名前×日付の表に押した時刻が入っています)
- **押し忘れの救済・取り消し** → 「出席」シートの該当セルに時刻(例 `06:45`)を書く/消すだけ
- **集計・グラフ** → スプレッドシートなので、そのまま関数やグラフが使えます

## 注意点

- プログラム(コード.gs や index.html)を修正した場合だけは、「デプロイ」→「**デプロイを管理**」→ ✏(編集)→ バージョン「**新バージョン**」→「デプロイ」が必要です。**シートの書き換えだけなら何もしなくて大丈夫です。**
- URLが `script.google.com/macros/…` という長い見た目になります。気になる場合は、Googleサイト(無料のホームページ作成)にこのウェブアプリを埋め込んで、見た目のよいページにすることもできます。
- 無料枠の目安: 1日あたりの実行回数などに上限がありますが、50人規模の朝活なら余裕で収まります。
