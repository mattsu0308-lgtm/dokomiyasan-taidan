# まっちのレシピ図鑑 PWA

**Instagramに埋もれた過去投稿を、フォロワーが自分で探せる"レシピ図鑑"に変えるPWA。**

Instagramではプロフィールから過去のレシピを探しにくい。このアプリは、
プロフィールリンクから来たフォロワーが「食材」や「気分」でレシピを探し、
Instagramの動画に戻って作れるようにするためのもの。

## いまの段階: MVP v0.1

検証したいことはひとつ:
**「フォロワーがプロフィールリンクから来て、レシピを探して、Instagram動画に戻るか」**

### v0.1に入っているもの

- スマホ向け公開ページ: ホーム / さがす / レシピ詳細 / まとめ
- キーワード検索+タグ絞り込み(タグ検索が主軸)
- 「Instagramで動画を見る」CTA
- seedデータ36件(**全件が明確にダミーとわかるサンプル**。実在の投稿ではない)
- 将来拡張できるDBスキーマ(`supabase/migrations/0001_init.sql`)
- 最低限のPWA manifest(ホーム画面追加でアプリ風表示)

### v0.1に入っていないもの(意図的に後回し)

Instagram API連携 / cron / トークン自動更新 / 再生数自動取得 /
特集自動生成 / AI検索 / 管理画面 / マルチテナントUI / オフライン対応

## 動かし方

```bash
npm install
npm run dev   # http://localhost:3000
```

v0.1はローカルseedデータで動く(外部サービス不要)。
Supabaseに投入する場合は `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` を
設定して `npx tsx scripts/seed.ts`。

## 運用コストについて

自分用MVPはVercel/Supabase無料枠で月額0円を目指す。
**ただし、他クリエイターへの商用提供・販売・継続運用では、Vercel Hobbyなどの
無料枠に依存しない。商用時はVercel Pro等の有料プラン、または別ホスティングを
前提にする。**「完全無料で販売できる」ものではない。

## 将来の商品設計: 「Instagramレシピ資産化パック」(仮)

アプリ単体ではなく、以下をセットにしたパッケージとして展開する構想:

- 過去投稿の取り込み
- レシピ図鑑PWA作成
- 食材・気分・季節・用途タグの整理
- Meta連携サポート(伴走方針は `docs/meta-integration-policy.md`)
- プロフィールリンク導線設計
- ハイライト/固定投稿/リール末尾CTAの提案
- 投稿CTAテンプレ作成
- 初月の改善レポート

差別化は「アプリ」ではなく:
①Meta連携の面倒さを伴走で超えさせる ②Instagram運用目線のタグ設計
③過去投稿を検索される資産に変える ④導入後の運用改善まで見る
