# レシピ取り込みCSVスキーマ(Phase 2用)

このリポジトリには実データ(`reels_cleaned.csv`)は含まれていない。
実データ投入(Phase 2)は、ユーザーがCSVを提供したときにのみ行う。
**存在しない実データの中身を推測して作ることは禁止。**

## 元データとの関係

別作業で Meta エクスポート ZIP から `reels_cleaned.csv`(リール189行:
投稿日・キャプション・字幕有無)が作成済み。本スキーマはその列構成を
土台に、アプリ側で必要になるタグ列を追記できる形にしたもの。
実CSVを取り込む際は、列名をこのスキーマにマッピングする。

## 列定義

| 列 | 必須 | 説明 |
|---|---|---|
| `posted_at` | ○ | 投稿日時(ISO 8601) |
| `title` | ○ | レシピ名。キャプションから抽出して整えたもの |
| `caption` | ○ | キャプション全文 |
| `permalink` | △ | InstagramリールのURL。**Metaエクスポートにはpermalinkが含まれない**ため、空の場合がある。空の行は「Instagramで動画を見る」CTAをプロフィールリンクにフォールバックするか、手動でURLを補完する |
| `has_subtitles` | - | 字幕(.srt)があるか(true/false) |
| `video_filename` | - | エクスポート内の動画ファイル名(照合用。アプリでは未使用) |
| `ingredient_tags` | ○ | 食材タグ。`\|` 区切り。正規化済みであること(豚こま/豚バラ/豚ひき肉→豚肉) |
| `mood_tags` | ○ | 気分・用途タグ。`\|` 区切り(docs/plan.md の統制語彙を使う) |
| `cuisine` | - | 和/洋/中/韓/エスニック/その他 |
| `difficulty` | - | かんたん/ふつう/本格 |
| `time_minutes` | - | 目安調理時間(分) |
| `manual_score` | - | 人気順の手動スコア(大きいほど上位)。投稿別再生数はエクスポートに存在しないため、これで代替する |
