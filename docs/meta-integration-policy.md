# Meta連携の伴走方針(販売時)

将来、他のクリエイターに「Instagramレシピ資産化パック」として提供する際の
Instagram/Meta連携の進め方。**Phase 4(販売検証)以降に適用する。**

## 基本方針

中央のMetaアプリで全クリエイターをOAuth連携させる「完全SaaS方式」は、
初期段階では採らない(アプリ審査・ビジネス認証・保守負担が大きいため)。

代わりに:

**各クリエイターが自分のMeta Developerアプリを作成し、
自分のInstagramアカウントのみを接続する。
まっちは画面共有で、Metaアプリ作成 → Instagramテスター承認 →
長期トークン取得 → 管理画面への登録までを伴走サポートする。**

## 絶対に守ること

- **クライアントのInstagram/MetaログインID・パスワードは預からない**
- **認証作業は必ず本人が行う**
- **トークンやシークレットは、本人が本人の管理画面に入力する**
- まっちは画面共有で案内するだけ(操作の代行をしない)

## サポートメニューに含めるもの

- 初回のMetaアプリ作成・テスター承認・トークン取得の伴走(画面共有)
- **トークン期限切れ(60日)時の再取得・再接続の案内**
- 接続エラー時の切り分けサポート

## 技術メモ(Phase 3/4 実装時の前提)

- 利用API: Instagram API with Instagram Login(プロアカウント必須)
- 自分のアカウントのみ接続する場合、Metaアプリは開発モードのままでよく、
  Metaのアプリ審査は不要
- 投稿別の再生数(views)取得は**任意機能**とする。仕様変更の影響を
  受ける可能性があるため、取得できなくてもアプリが成立する設計
  (`view_count` nullable、人気順は `manual_score` / `posted_at` で代替)
