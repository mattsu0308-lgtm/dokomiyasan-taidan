# ☀️ 夏の朝活ラジオ体操スタンプラリー

夏休みのラジオ体操スタンプカードをそのままWebアプリにしたものです。
決まった朝の時間帯(例: 6:30〜7:00)にアクセスして「今日のスタンプを押す!」を押すと、
自分のカードのその日のマスに赤いハンコが押されます。全員のカードが1つの画面に並ぶので、
「あの人も溜まってるな〜」がお互いに見えて盛り上がります。

## 仕組み

- **一括共有型**: カードは1つの画面にみんな分並びます。名前を入力して初回スタンプを押すと自動で自分のカードが作られます。
- **時間帯はサーバー側で判定**: 受付時間外はボタンが押せません(端末の時計をいじってもズルできません)。時刻は日本時間(JST)基準です。
- **1日1回まで**: 同じ日に2回は押せません。
- **ごほうびライン**: 5日・10日・20日・皆勤 などの達成バッジが自分のカードに表示されます(内容は設定で自由に変更可)。
- **押し忘れの救済**: 管理者だけがパスワード付きAPIで後からスタンプを追加/削除できます。

## 起動方法

Node.js(v18以上)だけで動きます。パッケージのインストールは不要です。

```bash
cd radio-taiso-stamps
node server.js
# → http://localhost:3000 で開く
```

スタンプのデータは `data/stamps.json` に保存されます(サーバーを再起動しても消えません)。

## 設定(config.json)

| 項目 | 意味 | 例 |
|---|---|---|
| `eventName` | イベント名 | 夏の朝活ラジオ体操スタンプラリー |
| `startDate` / `endDate` | 開催期間 | 2026-07-01 〜 2026-07-31 |
| `windowStart` / `windowEnd` | 受付時間帯(JST) | 06:30 〜 07:00 |
| `excludeWeekdays` | お休みにする曜日 (0=日〜6=土) | `[0, 6]` で土日休み |
| `rewards` | ごほうびライン | `{ "days": 10, "label": "ジュース賞 🧃" }` |
| `adminPass` | 管理者パスワード(**必ず変更してください**) | |
| `testMode` | `true` にすると時間帯に関係なく押せる(動作確認用) | |
| `port` | ポート番号 | 3000 |

設定を変えたらサーバーを再起動してください。

## 運用のしかた(おすすめ)

1. **時間帯を決める**: 例えば 6:30〜7:00 の30分。`config.json` に設定。
2. **集合場所を決める**: バーチャャルオフィス(oVice等)の一角、またはZoomの定例ミーティング。
   - oViceなら: オフィス内の「朝活コーナー」にこのアプリのURLを貼った看板/リンクオブジェクトを置く。朝来た人はその場でURLを開いてスタンプ。
   - Zoomなら: 毎朝の定例URLに入室 → ホストがチャットにこのアプリのURLを流す → 各自スタンプ。
3. **朝の流れ**: 集合 → ラジオ体操 or 朝のひとこと → 各自スタンプを押す(受付時間内なら押した時刻も記録されます)。
4. **ごほうび**: 期間終了後、達成バッジに応じてプレゼントを渡す 🎁

> ズル防止は「受付時間帯のみ押せる」ことで担保していますが、厳密には性善説の運用です。
> より厳密にしたい場合は、朝会のZoom/oVice上でだけ合言葉を発表して名前と一緒に入力してもらう、などの運用で補えます。

## 公開(みんなが使えるようにする)方法

社内の誰でもアクセスできるURLが必要です。いずれか1つでOKです。

- **Render / Railway / Fly.io などのPaaS**(無料枠あり・一番かんたん):
  このフォルダをそのままデプロイし、起動コマンドを `node server.js` にするだけ。
  ※無料プランはスリープでファイルが消えることがあるので、有料の永続ディスクか、こまめなバックアップ(`data/stamps.json` を保存)がおすすめ。
- **社内サーバー / 常時起動PC**: `node server.js` を動かして社内LANのURLを共有。
- **お試し(一時的)**: 自分のPCで起動して `cloudflared tunnel --url http://localhost:3000` などで一時URLを発行。

## 管理者用API(押し忘れの補完)

```bash
# 7/3のスタンプを「まつだ」さんに追加
curl -X POST https://<アプリのURL>/api/admin/stamp \
  -H 'Content-Type: application/json' \
  -d '{"pass":"<adminPass>","name":"まつだ","date":"2026-07-03","time":"06:45"}'

# 取り消す場合
curl -X POST https://<アプリのURL>/api/admin/stamp \
  -H 'Content-Type: application/json' \
  -d '{"pass":"<adminPass>","name":"まつだ","date":"2026-07-03","remove":true}'
```
